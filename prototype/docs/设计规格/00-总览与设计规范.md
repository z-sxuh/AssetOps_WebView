# 00 · 总览与设计规范

> 用途：跨端还原「工作台」界面时的**统一设计基准**。所有页面规格（01–11）共享本文件中的令牌、字体、间距与通用组件定义。凡页面文件中写"见规范 §X"，即指本文件对应小节。
>
> 基准来源：对应发布版本的 `src/styles.css`、`src/squircle.css`、`src/appTheme.ts`、`src/components/*`。默认主题为 **spring（早春）**，预览截图即为该主题。

---

## 1. 尺寸与单位约定

- 参考设计稿分辨率：**1440 × 900**（窗口 1440×900 时侧栏展开 164px）。最小支持窗口宽度 **1000px**（`body{min-width:1000px}`）。
- 所有数值单位均为 **逻辑像素（dp/pt）**，跨端可直接 1:1 使用。
- 滚动条**全局隐藏**（`*{scrollbar-width:none}` + `::-webkit-scrollbar{width:0;height:0}`）。跨端实现可隐藏滚动条但保留滚动能力。
- 全局 `box-sizing:border-box`。

## 2. 主题机制

支持三套主题，通过根节点 `data-theme` 切换：

| 主题 | 选择器 | 说明 |
|---|---|---|
| light（默认浅色） | `:root` | 中性灰蓝 |
| **spring（早春，默认启用）** | `:root[data-theme='spring']` | 浅绿系，**预览图与本文档主基准** |
| dark（浅夜） | `:root[data-theme='dark']` | 深色 |

> spring 只覆盖下表中列出的变量，未列出的变量（如 `--blue`、`--amber`、`--coral`、`--purple` 等）沿用 light 值。

### 2.2 AntD 组件主题（appTheme.ts）

- `colorPrimary`：spring `#3c8058`；light `#287a54`；dark `#3bb77b`。

- **Input / Select**：背景=spring `#e4efdf`（即 `--inset`）。
- **Button**：`borderRadius:12`（改用 `--radius-control`）。

## 3. 字体系统

- 字族：`'Microsoft YaHei UI','Microsoft YaHei','Segoe UI',system-ui,sans-serif`（跨端可用系统无衬线回退，中文优先"微软雅黑"）。
- 正文基础：`14px`（`body`），AntD 控件默认 `13px`。
- 页面大标题 `h2`：`28px`，`letter-spacing:-0.45px`，`font-weight:600~700`，`line-height:44px`，颜色 `--ink`。
- 表头 `th`：`12px / 600`，颜色 `--ink`。
- 表格正文/行：`12px`。
- 次要说明文字：`12~13px`，颜色 `--muted`。
- 设置项标题 `settings-row > b`：`14px`，颜色 `--ink`；说明 `14px`（small `13px`）`--muted`。
- 设置分组标题：`18px / 600`，颜色 `--muted`。
- 等宽（路径/cron）：`Consolas, monospace`。

## 4. 间距 / 圆角 / 阴影 / 动效

### 4.1 间距
- 常用间距梯度：**4 / 6 / 8 / 10 / 12 / 13 / 14 / 16 / 18 / 20 / 22**。
- 页面内容内边距：`.page-content{padding:12px}`；内容区最大宽度 `1600px`（台账/运维/字段定义/导入导出页 `max-width:none`，铺满）。
- 卡片内边距：`panel-card` body `16px 18px`，head `min-height:48px; padding:0 18px`。
- 卡片/区块间距：`14px`（module-page 用 `display:grid;gap:14px`；dashboard 用 `18px`）。

### 4.2 圆角（squircle.css）
| 变量 | 值 | 用途 |
|---|---|---|
| `--radius-control` | `12px` | 按钮、输入、选择器（主控件圆角） |
| `--radius-compact` | `10px` | 小控件/紧凑圆角 |
| `--radius-panel` | `16px` | 大卡片/面板/侧栏树卡片 |
| `--radius-popup` | `14px` | 弹出层（Popover/Dropdown） |
| `--radius-dialog` | `18px` | 对话框 Modal |
| `--radius-popup-item` | `10px` | 下拉项 |
- 菜单项圆角 `10px`；页内按钮 `10px`（`.page-heading .ant-btn`）；标签 Tag 圆角随 AntD 默认（小圆角）。
- 支持 `corner-shape:squircle` 的矩形面走 squircle 平滑圆角（跨端可用等价圆角近似）。

### 4.3 阴影
- 卡片：`box-shadow: 0 4px 22px var(--shadow-soft)`（`panel-card`）。
- 浮起元素（primary 按钮、下拉）：`0 1px 3px var(--shadow-raised)`。
- 菜单选中项：`0 1px 3px`（`--shadow-raised`）。

### 4.4 动效
- 侧栏折叠/展开过渡：`.28s cubic-bezier(.22,.8,.24,1)`。
- 操作列展开/收起：`ledger-actions-*` 关键帧动画（见 03 文档）。

## 5. 通用组件规范

> 建议：用主题 + 自定义组件统一这些外观；不要直接套用框架默认样式（会改变阴影/圆角/字重）。

### 5.1 按钮 Button
- 默认圆角 `12px`（`.ant-btn:not(.ant-btn-circle)`、`.page-heading .ant-btn` → `--radius-control`）。
- 页内工具按钮高 `30px`、`font-size:12px`（模块工具栏内）；页标题区按钮高 `35px`、`radius:10px`、`font-size:13px`。
- Primary：填充 `--green`，文字 `--accent-ink`，`box-shadow:0 1px 3px var(--shadow-raised)`，**无外发光**。
- Default：背景 `color-mix(surface 90%, transparent)`，边框 `--border-soft`。
- Danger：文字/描边 `--coral`（危险按钮如"重新初始化""删除"用红色描边文本按钮）。
- Text 按钮（表格行内"详情/编辑"）：无背景无边框，`--blue` 或 `--ink`，hover 背景 `--selection`。

### 5.2 输入 / 选择
- 输入框、Select 背景 `--inset`，边框 `1px --border-soft`，圆角 `12px`，高度默认 `34px`。
- 聚焦态：边框 `--green`（spring）。
- 尺寸变体：台账工具栏内 `height:30px`；字段筛选等弹层内按页面规格给固定宽度。
- 搜索框：圆角 `8px`，背景 `--inset`；全局搜索宽 `360px`、高 `35px`。

### 5.3 卡片 Card（`.panel-card`）
- `border:0`；`border-radius:16px`；`box-shadow:0 4px 22px var(--shadow-soft)`；背景 `--surface`。
- head：`min-height:48px`、`padding:0 18px`、标题 `14px / 600`、底部 `1px --line`。
- body：`padding:16px 18px`。
- 表格页的 `fixed-table-card`：body `padding:0`，占满高度、表头吸顶。
- 树上卡片 `tree-panel` 见 03。

### 5.4 标签 Tag
- 语义色：`green`（绿）、`blue`（蓝）、`gold/amber`、`volcano/orange`、`red/coral`。
- 样式：文字=对应色，`border`=`色 35% 透明`，`background`=`色 12% 透明`，`bordered:false` 时无边框。
- 状态 Tag（资产状态）：生产=green，测试=blue，待切换=gold，关机=中性灰。

### 5.5 表格 Table
- 表头：背景 `--table-header`、文字 `--ink`、`th` `padding:12px 10px`、`12px / 600`、`white-space:nowrap`、内容**居中**（台账表 `th` 居中）。
- 行：`font-size:12px`，背景透明，行间 `1px --line` 分隔。
- 行 hover：背景 `--hover`。
- 复选列：左侧固定勾选。
- 固定列：`fixed:left`（服务器名称、主机名）、`fixed:right`（操作列，宽 144，见 03）。
- 分页：居中（台账）/右对齐（备份），`margin:12px 15px 14px`，`font-size:12px`，默认 `25 条/页`。

### 5.6 弹出层 Popover / Dropdown / Modal
- Popover 圆角 `14px`，内边距 `8px`，阴影浮起。
- 下拉项圆角 `10px`，hover 背景 `--hover`。
- Modal 圆角 `18px`；导入字段映射 Modal 宽 `740px`。
- 字段筛选 Popover 宽 `500px`（`max-width: calc(100vw - 64px)`），见 03。

### 5.7 其它
- **Switch**：右侧开关，开=`--green`。
- **Segmented**：导入/导出切换，选中底 `--nav-fill`（或 `--green` 高亮），胶囊化。
- **Tabs**：下划线指示器 `--green`，选中文字 `--ink`，未选 `--muted`，`font-size:13~14px`。
- **Steps**：导入 4 步，见 07。
- **Tooltip**：深底反白，圆角 `10px`。
- **Empty**：简单线条插画 + 次要文字。
- **图标**：AntD Outlined 体系（`@ant-design/icons`），线性描边，默认 `16px`；侧栏菜单图标 `16px`；页脚按钮 `16px`。

## 7. 跨端落地要点（全局）

1. **主题先行**：把 §2 的三套色板做成 `ThemeExtension`/常量类，所有页面引用语义色（ink/muted/line/surface/…）而非硬编码十六进制，便于换肤。
2. **圆角统一**：全局 `InputDecorationTheme`、`ElevatedButtonTheme`、`CardTheme` 用 `--radius-control/panel`，避免 Material 默认 4/28px 圆角。
3. **隐藏滚动条**：`ScrollConfiguration` 包住整棵滚动树，`scrollbars:false`。
4. **固定最小宽**：桌面窗口 `minWidth:1000`；侧栏宽度用状态驱动 `164 ↔ 72`，主区 `marginLeft` 同步。
5. **表格**：优先用 `DataTable` 或自建 `Row/Column` 网格以精确控制列宽、固定左右列、表头吸顶、行 12px 字。
6. **不要引入响应式卡片折叠**：此应用是桌面固定布局，断点仅按 §11 的 5 档收缩（不改结构，只调列数/内边距/面板宽）。
