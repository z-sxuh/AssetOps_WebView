# 01 · 应用外壳（窗口框架）

> 覆盖：窗口标题栏、侧边栏（展开/折叠）、品牌区、导航菜单、主区域、顶部全局搜索、页脚。所有页面都嵌在此外壳的 `.main-layout > .content-area` 内。
>
> 源：`src/components/WorkbenchLayout.tsx`、`src/styles.css`（标题栏/侧栏/页脚/内容区）。

---

## 1. 总体布局树

```
app-shell (Layout, height:100vh, overflow:hidden)
├─ window-titlebar  (fixed, top:0, height:32, z-index:5, flex)
│   ├─ .window-titlebar-sidebar  (width:164 展开 / 72 折叠；border-right 1px --line)
│   └─ .window-titlebar-drag  (flex:1 可拖动区，右侧窗口控制按钮)
│       └─ .window-controls (最小化 / 最大化 / 关闭)
│           └─ button ×3 (each 46×32)
├─ sidebar (Layout.Sider, fixed, left:0, width:164 展开 / 72 折叠, height:100vh, z-index:4)
│   ├─ .brand  (height:76)
│   │   ├─ .brand-mark.brand-image (38×38, radius:12) > img(logo)
│   │   └─ .brand-copy  > b「工作台」 / (small 副标题)
│   ├─ .ant-menu  (padding:0 11px, 导航项列表)
│   └─ .sidebar-bottom  (justify-content:flex-end; padding:12px 15px; border-top 1px --line)
│       └─ .collapse-button (34×34 折叠/展开按钮)
└─ main-layout (margin-top:32; height:calc(100vh-32); margin-left:164 展开 / 72 折叠)
    ├─ .topbar (absolute, top:12, right:0, height:44, padding:0 12px)  ← 顶部右侧操作区
    │   └─ .top-actions > GlobalSearch / 搜索触发按钮
    ├─ .content-area (flex:1; overflow:auto)  ← 当前页面内容
    │   └─ .page-content (max-width:1600; margin:0 auto; padding:12)
    └─ .app-footer (height:30; 见 §6)
```

- 侧栏与标题栏固定在窗口：`sidebar` `position:fixed`；`window-titlebar` `position:fixed;top:0`；`main-layout` 用 `margin-top:32` 避让标题栏、`margin-left` 避让侧栏。
- `body{min-width:1000px}`；`.app-shell{height:100vh;overflow:hidden}`。

## 2. 窗口标题栏 `.window-titlebar`

| 属性 | 值 |
|---|---|
| 位置 | `position:fixed; top:0; left:0; right:0` |
| 高度 | `var(--titlebar-height) = 32px` |
| 层级 | `z-index:5` |
| 布局 | `display:flex` |
| 背景 | 与页面 chrome 一致（浅色时近 `--chrome`/透明混合） |

- `.window-titlebar-sidebar`：宽 `164px`（展开）/ `72px`（折叠），`border-right:1px solid var(--line)`，让标题栏左侧与侧栏对齐。
- 应用图标/标题在左侧（`.brand-mark` 内 logo + "工作台"文字，见品牌区）。
- 右侧 `.window-controls` 三个按钮（最小化 ▢ 最大化 ✕），每个 `width:46px; height:32px; font-size:12px`；关闭按钮 hover 背景 `#c42b1c`（红）文字白。
- 按钮图标：`—`（最小化）、`▢`（最大化/还原）、`✕`（关闭）。

> 桌面端若用自定义标题栏：高度 32，右侧三按钮各 46×32，关闭 hover 红底；若用系统标题栏，则保留 32px 顶部占位。

## 3. 侧边栏 `.sidebar`

### 3.1 容器
| 属性 | 展开 | 折叠 |
|---|---|---|
| 宽度 | `164px` | `72px` |
| 定位 | `position:fixed; left:0; top:0` | 同 |
| 高度 | `100vh` | `100vh` |
| 右边框 | `1px solid var(--line)` | 同 |
| 背景 | `color-mix(in srgb, var(--sidebar) 78%, transparent)` + `backdrop-filter: blur(20px) saturate(1.25)` | 同 |
| 层级 | `z-index:4` | 同 |
| 过渡 | `width .28s cubic-bezier(.22,.8,.24,1)` | 同 |

- 半透明毛玻璃：底色为 `--sidebar`（spring `#e1eddc`）78% 混透明，叠加 `blur(20px) saturate(1.25)`。跨端用等价模糊（blur 20）叠加半透明底色实现。

### 3.2 品牌区 `.brand`
- 高度 `calc(44px + 32px) = 76px`（44 内容高 + 32 标题栏占位）。
- **Logo 块 `.brand-mark`**：`38 × 38`，`border-radius:12px`，背景渐变 `linear-gradient(145deg, #4c91eb, #2869cc)`（蓝紫渐变），内含白色线条 logo（近似字母 Z 的折线标识）。
- **展开态定位**：`brand-mark` 绝对定位 `left: calc(50% - 51.5px)`；`brand-copy` `left:79px`，垂直居中。品牌文字 `b`：`20px / 700`，颜色 `--ink`，内容"工作台"；`small` 副标题 `16px`（可放英文/版本，预览中为 logo 旁标题）。
- **折叠态**：`brand-mark` `left: calc(50% - 19px)`（水平居中），`brand-copy` 隐藏。

### 3.3 导航菜单 `.sidebar .ant-menu`
- 菜单容器：`padding: 0 11px`；菜单项为竖排列表。
- **菜单项 `.ant-menu-item`**：
  | 属性 | 值 |
  |---|---|
  | 高度 | `42px` |
  | 外边距 | `3px 0` |
  | 圆角 | `10px`（另一处覆盖为 16px，以 10px 为准，视觉应与选中胶囊一致） |
  | 字号 | `13px` |
  | 字重 | `600` |
  | 默认文字色 | `var(--muted)` |
  | 图标 | `left:13px`、`width:16px`、`font-size:16px`（线性图标） |
  | 标题文字 | `left:44.5px`（图标右侧，间距约 15px） |
- **选中态**：`background: var(--nav-fill); color: var(--nav-ink); box-shadow: 0 1px 3px var(--shadow-raised)`，形成圆角胶囊填充；图标与文字同色变 `--nav-ink`。
- **hover 态**：背景 `--hover`（轻）。
- **折叠态**：仅显示居中图标，图标 `left: calc(50% - 8px)`（约 16.5px from left），文字隐藏；选中胶囊仍为 42×42 圆角块。

## 5. 顶部搜索区 `.topbar` / `.global-search`

- `.topbar`：`position:absolute; top:12px; right:0; height:44px; padding:0 12px`，横向排列右侧操作（搜索）。
- **全局搜索**：`.global-search` `width:360px; height:35px; border-radius:8px; background:var(--inset)`，内含搜索放大镜图标 + 占位文字；快捷键提示 `F4` 唤起全局搜索。
- **搜索触发按钮**：`.header-search .search-trigger` `42×42; border-radius:12px; font-size:22px; color:var(--blue); background:var(--chrome)`；展开后搜索框宽度过渡到 `180px`。
- 页面右上角常驻一个圆形/方形搜索按钮（预览各页右上角均有一个放大镜按钮，`42×42`，圆角 12，图标蓝 `--blue`）。

> 说明：页标题 `.page-heading` 本身也可含页面级操作按钮（各页文档详述）；顶部 `.topbar` 的搜索按钮浮动于内容右上，需注意与页标题按钮不重叠（页标题右侧留出约 60px 空间或按钮排在标题左侧区内）。预览中搜索按钮位于窗口右上、页标题下方内容之上。

## 7. 响应式（外壳部分）

- `body` 最小宽 `1000px`：窗口低于 1000 出现横向滚动（窗口最小宽度设为 1000）。
- 侧栏在窄窗口（如 1100×900 预览）**仍保持展开 164px**（不自动折叠）；折叠由用户手动点底部按钮触发，折叠为 72px。
- 折叠后主区 `margin-left:72px`，菜单仅图标；其余页面断点见 `11-解锁初始化与响应式.md`。

## 8. 跨端实现要点
- 用 `Row`：`SizedBox(width: sideWidth)` 侧栏 + `Expanded` 主区；`sideWidth` 是 `ValueNotifier<int>`（164/72），用 `AnimatedContainer(duration:.28s, curve:Cubic(.22,.8,.24,1))` 过渡宽度，主区 `AnimatedPadding(left:)` 同步。
- 侧栏背景：`ClipRect > BackdropFilter(blur 20) > Container(color: sidebar.withOpacity(.78))`。
- 顶部标题栏可用 `Stack`：底层内容，顶层 `Positioned(top:0,height:32)` 半透明条 + 右侧三按钮。
- 菜单项选中用 `Container(decoration: BoxDecoration(color: navFill, borderRadius:10, boxShadow:[...]))` 包裹图标+文字。
- 页脚用 `Container(height:30)` + `Row`，右侧锁图标绿色、刷新/主题 26×26 按钮。
