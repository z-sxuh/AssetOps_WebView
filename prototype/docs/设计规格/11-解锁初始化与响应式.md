# 11 · 解锁页 / 初始化页 / 响应式

> 覆盖：`?gate=unlock` 解锁页、`?gate=setup` 初始化页（Gate），以及全站响应式断点与窄/宽窗口表现。源：`src/styles.css` Gate 样式、`src/components/Gate*.tsx`、各响应式 `@media`。

---

## 1. 门面（Gate）通用

- 全屏铺满窗口，无侧栏/页脚。
- 背景：页面渐变（`--background-top → --background-bottom`），spring 主题下为浅绿→更浅绿的柔和渐变；带轻微模糊/光晕。
- 左上角：品牌标（`.brand-mark` 38×38 渐变蓝圆角 12 + "工作台"文字），距窗口左上约 20–24px（与标题栏内位置一致）。
- 内容区：水平垂直**居中**（`Center`）。
- 无导航、无搜索、无页脚。

---

## 2. 解锁页（gate=unlock）

- 布局：居中一个**窄密码输入卡**（`.gate-card.gate-unlock`）。
- 卡片尺寸：
  - 宽 `min(280px, 100%)`（视觉上是一个胶囊输入条，非大卡片）。
  - 高约 `44–48px`，圆角 `16px`，背景 `--surface`/`--chrome`，带边框与内阴影。
- 内部一行：**密码输入框**（占位"请输入主密码"）+ 右侧两个图标按钮：`显示/隐藏密码`（眼睛）+ `锁形提交`（lock）。
  - 输入框无可见边框（与卡融合），背景透明/`--inset`。
  - 聚焦时整条卡片描边 `--green`（spring 高亮环）。
  - 眼睛图标切换明文/密文；锁图标点击提交解锁；回车提交。
- 错误态：卡片轻微红描边 + 抖动/提示（可选）。
- 预览核对（16 解锁界面）：窗口 1920×900，背景浅绿渐变，正中一个约 250×48 的密码输入条（左"请输入主密码"，右眼睛+锁图标），左上角品牌。

## 3. 初始化页（gate=setup）

- 布局：居中一张**较宽设置卡**（`.gate-card`）。
- 卡片尺寸：
  - 宽 `min(410px, 100%)`。
  - `padding:13px 7px 5px`（外卡），内部 body `padding:23px 28px 21px`。
  - 圆角 `16px`，背景 `--surface`，阴影浮起。
- 内部纵向结构：
  1. **图标块**：约 `40×40`，圆角 ~12，背景 `--inset`（浅绿），内含盾牌/锁图标（`--green`）。
  2. **标题**"设置主密码"：`20px / 700`，`--ink`。
  3. **副标题**"主密码用于加密本地资产数据，请妥善保管。"：`13px`，`--muted`。
  4. **字段「主密码」**：标签 `13px/600 --ink` + 密码输入框（占位"请输入主密码"，右侧眼睛图标），高 34–38，圆角 12，背景 `--inset`，聚焦绿边框。
  5. **字段「再次输入」**：标签 + 密码输入框（占位"确认主密码"，眼睛图标）。
  6. **主按钮**"创建加密数据仓库"：**全宽**，高约 `40–44px`，圆角 12，填充 `--green`，白字 `15px/600`。
  7. **底部提示**"应用不强制密码强度，建议使用复杂密码并妥善保管。"：`12px`，`--amber`（琥珀/橙）小字。
- 预览核对（17 初始化界面）：卡片居中约 410px 宽；图标 + "设置主密码" + 副标题 + 两个密码框 + 绿色全宽按钮"创建加密数据仓库" + 橙色提示。

## 4. 响应式断点（全站汇总）

应用为桌面固定布局，断点只**收缩列数/内边距/面板宽**，不改变信息结构。`body{min-width:1000px}`（窗口 <1000 横向滚动）。

| 断点 | 影响 |
|---|---|
| **@1500px** | Dashboard：底部区块转 2 列；`recent-changes-panel` 跨整行（`grid-column:1/-1`）。 |
| **@1250px** | `project-grid`（单位/项目）转 3 列；`kpi-grid` gap 收为 9；`module-grid` 转**单列**（`1fr`）。 |
| **@1200px** | 工作日历 `--reminder-width` 收为 `280px`；日格 `padding:7`；`marks` 字号 10。 |
| **@1150px** | `markdown-editor-grid` 转单列；`module-toolbar` 内 Select `max-width:100%`；Dashboard 单位柱状 `project-grid` 按 `min(count,2)`；`dashboard-heading` gap 收窄为 8。 |
| **@1100px** | 运维：`operations-workspace` padding 收为 12；`system-info-layout` 转单列（编辑器在上、关联资产在下，下方面板 `max-height:210`）；`module-storage`（页脚存储位）换行。 |

## 5. 窄窗口（14 窄窗口 · 1100×900）

- 侧栏**保持展开 164px**（不自动折叠）。
- 资产台账：左树宽约 218；右表格列被横向裁切（可横向滚动），行高不变；底部统计/分页仍在。
- 内容区宽度 = 1100 − 164 ≈ 936（减内容 padding 24）。
- 页标题、工具栏按钮 wrap 换行；不塌陷、不重排为移动端。

## 6. 宽窗口（15 宽窗口）

- 侧栏 164；内容区 `page-content` 在 ≤1600 时居中（两侧留白），>1600 时 `margin:0 auto` 命中 `max-width:1600` 居中；台账/运维/字段/导入页 `max-width:none` 铺满（宽窗时表格更宽、列更舒展）。
- Dashboard 卡片随宽度自适应（`cqi` 放大字号），环形图最大 220、柱宽最大 94。

## 8. 跨端实现要点
- Gate 页：`Scaffold` 全屏 `Container`(渐变背景) + 顶部品牌 `Positioned` + `Center` 卡片。
- 解锁：`Center` 内 `Container(width:~280,height:48,radius16)` + `Row(TextField + IconButton(eye) + IconButton(lock))`，聚焦 `border: green`。
- 初始化：`Center` 内 `Container(width:410, padding 23×28 21, radius16, shadow)` + `Column`（图标、标题、副标题、两密码框、全宽绿按钮、橙色提示）。
- 桌面窗口设 `minimumSize: Size(1000, 700)`；用 `MediaQuery`/`LayoutBuilder` 按上表断点调整 `crossAxisCount`、内边距、面板宽。
- 渐变背景用 `LinearGradient(begin: topCenter, end: bottomCenter, colors:[backgroundTop, backgroundBottom])`。
