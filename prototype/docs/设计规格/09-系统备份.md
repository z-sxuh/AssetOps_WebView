## 3. 留存策略卡

- `Card.panel-card`，标题"留存策略"，右上 extra 两按钮：`立即清理`（default）、`保存策略`（default）。
- 两个子区块，各含一行标签 + 5 个 `InputNumber`（带 `addonAfter` 单位后缀）：

  **自动备份留存** 与 **定时备份留存**（结构相同）：
  | 字段 | 默认值 | 后缀 |
  |---|---|---|
  | 保留最近 | `20` | 份 |
  | 每日保留 | `7` | 份/天 |
  | 每周保留 | `8` | 份/周 |
  | 每月保留 | `6` | 份/月 |
  | 每年保留 | `2` | 份/年 |

- 每个 `InputNumber` 宽约 90–120，后缀灰字；5 个横向均匀排布（`display:grid` 或 `Space`）。
- 区块之间留白，区块标题 `13~14px / 600 --ink`。

## 4. 备份列表卡

- `Card.panel-card.fixed-table-card`，标题"备份列表"，header extra：右对齐 `删除所选（n）` danger 按钮（无选中时禁用）。
- **表格列**：
  | 列 | 渲染 |
  |---|---|
  | （复选） | 勾选列 |
  | 文件名 | 上行文件名（如 `prototype-pre-import-2026-11-01T11-19-47-…json`，等宽小字）+ 下行完整路径（`12px --muted` 省略） |
  | 类型 | `Tag`：`导入前`（琥珀）/ `定时`（粉/红）/ `手动`（绿/中性） |
  | 大小 | `66 KB` / `61 KB` |
  | 创建时间 | `2026/11/1 19:19:47` |
  | 完整性 | `Tag` "恢复时校验"（蓝色描边 Tag） |
  | 操作 | 文本按钮 `恢复`（蓝，图标 Reload）/ `删除`（红，图标 Delete） |
- 表头吸顶、12/600、`--table-header` 底、居中；行 hover `--hover`。
- 底部 `.backup-pagination`：`justify-content:flex-end; margin:0; padding:6px 15px; border-radius:0 0 24px 24px; background:var(--surface)`，显示"N 份备份 | ‹ 1 › | 25条/页"（右对齐）。

## 7. 响应式
- 概要卡片 `minmax(160,1fr)`：窄窗口自动减少列数（4→3→2），不溢出。
- 备份表列多时横向滚动；留存策略 5 个输入框窄窗可换行。

---

## 8. 跨端实现要点
- `Column`：页头 + `SingleChildScrollView`（`backup-scroll-content`）内概要卡 + 留存策略卡 + `Expanded` 列表。
- 概要卡：`GridView.count(crossAxisCount:4)` 或 `Row(Expanded×4)`，数值大字 700。
- 留存策略：两组 `Wrap`/`Row` 各 5 个带后缀 `TextField`/`TextFormField`（`suffixText`）。
- 备份表：`DataTable`，文件名两行、类型/完整性用 `Tag`；底部右对齐分页。
- "立即备份""保存策略"primary/default 沿用 §00 规范。
