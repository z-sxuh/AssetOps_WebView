## 2. 页头按钮组（右）

从左到右：
1. `按月归档 ▾`（下拉：按月/按年等归档粒度）。
2. `月份` `DatePicker`（如 `2026年11月`，选择归档/筛选月份）。
3. `归档 ZIP（15）`（导出该月归档压缩包，括号为数量；图标 Download）。
4. `导入 ZIP`（导入历史归档包）。
5. `导出审计表`（导出审计表，图标 Download）。

- 按钮高约 35、圆角 10；均为 default 描边按钮（主操作不是 primary 高亮）。

## 4. 变更表

### 4.1 列
| 列 | 渲染 | 说明 |
|---|---|---|
| 时间 | 日期时间，如 `2026/11/1 19:19:47`，**可排序** | |
| 对象 | `<b>资产名</b>`（如"协同办公服务器"）+ 下行 `asset · <id>`（如 `asset-demo-6`，`12px --muted`） | 两行 |
| 操作 | `Tag`（编辑/新增/删除…，中性/蓝色 Tag） | |
| 来源 | `Tag`（手动/批量/导入/回滚/恢复/系统；"导入"用 gold/琥珀 Tag，"手动"蓝等） | |
| 变更摘要 | 文本，如"2 个字段：业务系统、账号与密码" | 长文本省略 |
| 批次 | chip（等宽小标签，如 `IMP-20261101…-f99`，浅底圆角） | |
| 操作 | 文本按钮 `详情`（Eye，蓝）/ `回滚`（Undo，蓝） | 右 |

- 表头吸顶、12/600、`--table-header` 底、居中。
- 行高约 56–64；hover `--hover`。
- 底部：`共 22 条变更` + 分页 `25 条/页`（居中或右）。

### 4.2 详情 / 差异对比（展开或抽屉/弹层）
- 点"详情"展示字段级差异。差异列表 `.diff-list{display:grid; gap:5}`。
- 单条差异 `.diff-item`：`display:grid; grid-template-columns:120px 1fr 18px 1fr; gap:8; font-size:12px` = 字段名 | 旧值 | 箭头 | 新值。
- 旧值 `.diff-old{color:var(--coral); text-decoration:line-through}`（红删除线）。
- 新值 `.diff-new{color:var(--green)}`（绿）。
- 箭头居中（→）。

## 8. 跨端实现要点
- 固定表页：`Column`（页头 + `Expanded` 表格卡片）。
- 筛选：`Wrap` 排 4 控件；搜索 `TextField` 前置 `search` 图标。
- 表格：列定义按上表；对象列两行（名称 + `asset · id` 小字）；操作/来源用 `Tag` 组件（琥珀/蓝/灰）。
- 详情差异：`showModalBottomSheet`/`Dialog` 内 `Column` 渲染 `diff-item` 行，旧值 `TextDecoration.lineThrough + coral`，新值 `green`，中间 `→`。
