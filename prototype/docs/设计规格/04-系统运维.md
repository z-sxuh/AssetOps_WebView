## 3. Tab：系统信息（system-info-layout）

### 3.1 布局
- `.system-info-layout{display:grid; grid-template-columns:minmax(0,1.7fr) minmax(210px,.8fr); gap:18px}`（左编辑器宽、右关联资产窄）。
- 说明：`@1100px` 时改为单列（`grid 1fr`，两行 `minmax(290,1fr) / minmax(130,auto)`，右面板 `max-height:210`）。

### 3.2 左：Markdown / 富文本编辑器
- `.markdown-tiptap{min-width:0; max-height:68vh; overflow:hidden; border:1px solid; border-radius:16px; background:color-mix(surface 92%, transparent)}`。
- 基于 Tiptap 富文本编辑器：
  - 顶部工具栏（一行图标）：标题级别、**B** 粗、*I* 斜、S 删除线、引用、有序/无序列表、表格、图片、附件、代码块等（`16px` 图标，按钮 28–30px，分隔线分组）。
  - 正文区：富文本内容（支持标题、段、列表、表格、图片/附件块），内边距约 14–16px，行高 1.6。
- 编辑器左下/工具条含保存类交互（"保存并记录版本"语义由工具栏/页签提供）。

### 3.3 右：关联服务器资产卡（system-assets-panel）
- 宽约 210–268px（`minmax(210,.8fr)`）。
- 顶部：`Select`（选择/新增关联资产）+ 标题"关联服务器资产"。
- 资产列表行：每行两行文本 = 名称（`13px/600`）+ `IP · 状态`（`12px --muted`）；行尾"打开台账"链接（`--blue`）。
- 面板可滚动（`overflow:auto`）。

### 3.4 预览核对（03 系统运维-资料）
- 顶部 scope："示例单位/生产环境/业务区/官网平台" + 描述输入行；右侧"导出系统资料""拓扑图导入/导出▾"。

- 主体：左富文本编辑器（工具栏 + 正文）；右"关联服务器资产"卡（Select + 资产行）。

## 4. Tab：网络拓扑（AntV X6 画布）

### 4.1 布局
- `.topology-viewport{position:relative; flex:1; min-height:240px; overflow:hidden; border:1px solid; border-radius:16px; background:var(--inset)}`。
- **有属性面板时**：`.has-properties{padding-right:292px}`（画布右侧留出属性面板空间）。
- **左上控制条 `.topology-controls`**：`position:absolute; left:12; top:12; padding:6; border:1px solid; border-radius:12; background:var(--surface)`，内含工具按钮：`选择` / `平移` / `连接`（分段按钮，选中高亮），有时含缩放/适应等。
- **右侧属性面板 `.topology-properties`**：`position:absolute; right:12; top:12; bottom:12; width:268; overflow:auto; padding:14; border:1px solid; border-radius:14; background:color-mix(surface 94%, transparent); backdrop-filter:blur(20px); box-shadow`。内含选中节点/边的属性编辑。
- **右下缩略图 `.topology-overview`**：`position:absolute; right:12; bottom:58; width:190; height:120; padding:6; border:1px solid; border-radius:12`（MiniMap）。
- **底部缩放条**：画布底部左/中显示缩放比例（如"-50% +"）与适应按钮。

### 4.2 节点与连线样式
- 节点矩形：`fill:var(--surface)`；`stroke:color-mix(green 55%, ...)`（绿色描边，约 1.5–2px）；圆角约 8–12。
- 节点标题文字：`15px / 700`，颜色 `--ink`。
- 连线（边）：`stroke:var(--muted); stroke-width:2`，可带箭头。
- 分组/区域：可用浅色包围框（区域色块）圈住子节点。
- 交互：拖拽移动、连线、缩放、MiniMap 导航。

### 4.3 预览核对（04 系统运维-拓扑）
- 三栏：左组织树 | 中 X6 画布（顶部"选择/平移/连接"工具条、节点+区域+连线、右下缩略图、底部缩放-50%+） | 右"素材库（台账资产/基础设备）+ 检查器"面板。

## 7. 响应式
- `@1100px`：工作区 padding 收为 12；`system-info-layout` 单列（编辑器在上、关联资产在下，下方面板 `max-height:210`）；`module-storage`（页脚存储位）换行。
- `@1150px`：`markdown-editor-grid`（若为双栏）转单列；工具栏内 Select `max-width:100%`。

## 8. 跨端实现要点
- 结构：`Row`（树 `SizedBox(width:218)` + `Expanded` 工作区卡片）。
- 工作区：`Container(padding:18, decoration(border,radius16,color:surface))` 内 `Column`：顶部 scope/动作行 + `TabBar/TabBarView`（`IndexedStack` 保活）。
- 系统信息：`Row`（`Expanded` 编辑器 + `SizedBox(width:~240)` 资产卡）。
- 富文本：用等价富文本组件还原 Tiptap 工具栏外观；工具栏按钮 16px 图标、分组分隔。
- 拓扑：用拓扑图组件或自绘；节点矩形 `fill=surface`、绿描边、标题 15/700；右下迷你图；右侧 268 属性面板浮层；左上分段控制条。
- 缩放条、MiniMap 用自定义浮层 `Positioned`。
