## 2. 左：组织目录树（OrgTreePanel）

### 2.1 宽度（动态）
- 初始宽 `218px`；运行时按最长节点文本动态计算：
  `width = round( max(218, min( ceil(最长文本 + 单位内边距), 420, 工作区宽 * 0.45 )) )`
  → 实际范围 **218–420px**，且不超过工作区 45%。跨端用可响应的状态持有宽度，命中上述 clamp。

### 2.2 卡片 `.tree-panel`
- `min-height:0; flex column; border:0; border-radius:16px; overflow:hidden; box-shadow:0 4px 22px var(--shadow-soft)`。
- **头部 `.ant-card-head`**：`min-height: var(--ledger-toolbar-height,55px); flex-shrink:0; padding:0 13px`；标题 `.head-title` `11px / 600; color:--ink`，内容"组织目录"。
- 头部右侧工具按钮（`.tree-toolbar .ant-btn`）：`26×26; border-radius:7px; font-size:12px`，依次：`＋`（新建）、结构传输、`展开全部`（折叠/展开）。

### 2.3 搜索框 `.tree-search`
- `padding:12px 20px; border-bottom:1px solid var(--line)`；内含搜索输入（圆角 8、背景 `--inset`），占位"搜索单位/环境/区域/系统"。

### 2.4 树内容 `.tree-menu-frame`
- `flex:1; min-height:0; overflow:auto; padding:9px 7px`。
- 树菜单 `.ant-menu`：`font-size:12px; 透明背景无边框`。

- 节点图标：单位/环境/区域用文件夹或节点图标，系统用文档/服务器图标，`14px`。

## 10. 跨端实现要点
- 结构：`Row`（树 `SizedBox(width: treeWidth)` + `Expanded` 表格列）。
- 树：`ListView` + 自绘层级导线（`CustomPaint` 画竖线+弯头），或用 `TreeView` 自定义。
- 表格：用 `DataTable2`/`PaginatedDataTable` 或自建 `Row` 网格，务必实现：表头吸顶（`SliverPersistentHeader`）、`th` 居中、列宽由内容测量、`fixed left` 两列 + `fixed right` 144 操作列、行 hover/选中色。
- 操作列：`Positioned(right:0,width:144)` 覆盖层，展收用 `AnimatedContainer` width 0↔144，左描边绿色 45% 混 `--line`、左投影。
- 工具栏按钮高 30、圆角 12；primary 绿色。
- "列宽"可用 `Table` + `defaultColumnWidth: IntrinsicColumnWidth()`，或测量文本后分配。
