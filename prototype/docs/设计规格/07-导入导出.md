## 2. 导入分支（importBody）

### 2.1 Steps（`src/features/import-export/ImportExportPage.tsx:439`）
- `Steps` 四步：`选择文件` → `预检记录` → `勾选记录` → `确认写入`，`margin-bottom:22`。
- 当前步高亮（`--green` 圆点/线），已完成步打勾，未到达步灰色。

### 2.2 步骤 0：选择文件卡 `.import-file-card`
- `Card.panel-card`，body 内边距 ~16–24。
- 上半：`Space` 一行「选择字段来源下载空模板：」+ `OrganizationSelect`（**宽 320px**，选择单位/环境）+ 按钮 `导出空模板`。
- 下半：**拖拽区 `Dragger`**（AntD Upload.Dragger）：
  - 大区域，**虚线边框、圆角 ~16px**，背景 `--inset` 或 `--surface` 浅色。
  - 居中内容：大图标 `InboxOutlined`（约 40–48px，`--muted`/`--blue`）+ 主文案「拖放或点击选择 Excel 工作簿」+ 次文案「仅支持 .xlsx；上传后交给应用解析。」（`--muted` 12–13px）。
  - 点击/拖入后进入预检。

### 2.3 步骤 >0：预检 / 勾选 / 确认
- 顶部 `Alert`：预览提示（文件已解析、记录条数、可覆盖/新增策略等）。
- **差异/选择表**（分页 10 条）：展示待导入记录与当前数据差异（新增/更新/冲突），带勾选列选择要写入的行；冲突行可用颜色标注（`.diff-old` 红删除线、`.diff-new` 绿）。
- 底部按钮组（右对齐）：`导出预检报告` | `取消` | `上一步` | `确认选择` | `确认导入`（primary）。
- 字段映射 Modal：`.import-mapping-modal` 宽 **740px**，内部：
  - `.import-mapping-columns{max-height:min(300px,38vh); overflow:auto}` 列出字段映射行。
  - 映射行 `.import-mapping-row`：`Text`（源列名，宽 200）+ `Select`（目标字段，`flex:1`）。

## 3. 导出分支（exportBody）

三张竖向堆叠的 `Card.panel-card`（gap 14）：

### 3.1 Card「导出范围」
- 4 个 `Radio`（纵向）：
  1. 整个项目
  2. 指定单位
  3. 指定系统
  4. 指定服务器
- 选"指定单位/系统/服务器"时，右侧/下方出现对应选择控件（下拉/树选择）。

### 3.2 Card「Sheet 预览」
- 表格：列 `Sheet 名` / `来源单位` / `行数` / `状态`。
- 状态列用 `Tag`（绿"就绪"）。
- 行数据按所选范围动态生成。

### 3.3 Card「导出选项」
- 3 个 `Checkbox`：
  1. 包含密码明文
  2. 包含字段说明 Sheet
  3. 包含变更历史 Sheet

### 3.4 底部动作
- 卡片组下方右对齐「导出 Excel」按钮（primary）。点击生成并下载 .xlsx。

## 7. 跨端实现要点
- `SegmentedButton`/自定义胶囊切换"导入/导出"。
- 导入：`Stepper`（纵向或横向四步）+ 步骤内容 `AnimatedSwitcher`。
- 拖拽区：虚线边框 + 点击选择文件，并支持拖放。
- 预检/差异表：`DataTable` + 分页 10；冲突行用红/绿文本。
- 导出：三卡片 `Column`，`RadioListTile`×4、表、`CheckboxListTile`×3，末尾右对齐 `ElevatedButton("导出 Excel")`。
- 字段映射用 `showDialog` 740 宽 + `ListView` 映射行（左文本 200 + 右下拉）。
