# 05 · 工作报告与工作日历

> 导航 key：`reports`｜标题：「工作报告」｜源：`src/features/reports/ReportsPage.tsx`、`src/features/reports/WorkCalendarView.tsx`、`src/styles.css`（180-217、1220-1238 日历，1095-1100 标题）。

## 1. 布局树

```
.page-content.report-page / module-page
├─ .page-heading  → <h2>工作报告</h2>
│                 右侧 .report-heading-actions（wrap）：
│                   单位选择▾ | 导入 | 导出 | 新增     （+ 搜索圆钮）
└─ .ant-tabs
   ├─ tab: entries   「工作记录」   → 工作记录表（见 §2）
   ├─ tab: reports   「报告归档」   → 归档报告表 + 报告周期工具（见 §3）
   └─ tab: calendar  「工作日历」   → 月历 + 提醒栏（见 §4）
```

- 三个 Tab 均在同一页签容器内；`tabBarExtraContent` 放当前 Tab 的批量操作（如"删除"）。
- 顶部操作按钮组与标题同行右对齐；`单位选择` 为下拉（示例单位/研发中心等）。

## 2. Tab「工作记录」（entries）

### 2.1 表格列（`ReportsPage.tsx`）
| 列 | 宽度 | 说明 |
|---|---|---|
| （复选） | — | rowSelection 多选 |
| 时间 | `175px` | 中国时区日期时间，如 `2026/11/1 19:19:47` |
| 类型 | `120px` | 标签/文本框：`完成事项 / 进行中事项 / 问题与风险 / 下期计划` |

## 3. Tab「报告归档」（reports）

### 3.1 报告周期工具 `.module-toolbar.report-cycle-toolbar`
- 左 `Space`：报告周期 `Select`（按周/按日）+ 对应 `RangePicker`（周）或 `DatePicker`（日）+ "包含工作记录时间" `Checkbox` + "收集"按钮。
- 右侧"批量删除"（选中时）。
- 生成/编辑报告：工具栏"保存正文""修订历史（n）""导出 Markdown"（`src/features/reports/ReportsPage.tsx:223`）。

### 3.2 归档报告表
- 列：`报告` / `更新时间`（`175px`） / `操作`（`64px`）。
- 表头通用样式；底部右对齐分页。
- 报告内容可用 Markdown 编辑器 + 预览（`.markdown-preview{padding:18;border:1px;border-radius:16px;background:mix(surface 88%);backdrop-filter:blur(20);max-height:65vh;overflow:auto}`）。

## 4. Tab「工作日历」/ 首页日历（WorkCalendarView）

### 4.1 布局
- 工具栏 `.work-calendar-toolbar`：`display:flex; justify-content:space-between; flex-wrap:wrap; gap:12; margin-bottom:18`。
  - 左：「‹ 2026年11月 📅 › 今天」（上一月/月份/下一月/回到今天）。
  - 右：「导入 导出 请假/外出/加班 新增提醒事项（primary）」。
- 主体 `.work-calendar-layout{display:flex; gap:20px; --reminder-width:340px}`：
  - 左：月历卡 `.work-calendar-month{flex:1; overflow-y:auto}`（`padding:18; border:1px; border-radius:16px; background:surface`）。
  - 右：提醒事项卡 `.work-calendar-task-slot{flex:0 0 var(--reminder-width)=340px; contain:size; overflow:hidden}` / `.work-calendar-tasks{padding:18;border:1px;border-radius:16px;background:surface}`。

### 4.2 月历网格
- 周标题 `.work-calendar-weekdays`：`grid repeat(7,minmax(0,1fr)); gap:8; margin-bottom:12; color:--muted; text-align:center; font-size:15px; font-weight:650`，内容"周一…周日"。
- 日期网格 `.work-calendar-grid`：`grid repeat(7,minmax(0,1fr)); gap:8`，42 格（含上下月补位）。
- **日格 `.work-calendar-day`**（v2 精确结构）：
  - `display:grid; grid-template-columns:minmax(0,1fr) max-content; grid-template-rows:auto auto 1fr auto; min-height: var(--calendar-day-height)=clamp(64px,9.5vh,96px); gap:4; padding:10; border:1px solid transparent; border-radius:10`。
  - 各行：
    - 日期数字 `date`：`grid-column:1; grid-row:1; font-size:20px; font-weight:750`（农历小字 `small 10px`）。
    - 农历 `lunar`：`grid-column:1/-1; grid-row:2; font-size:12px; color:--muted`。
    - 标记 `marks`：`grid-column:2; grid-row:1; display:flex; flex-direction:column; align-items:flex-end; font-size:12px; font-weight:600`（如请假/外出/加班小标）。
    - 工作时间记录 `day-events`：`grid-column:1/-1; grid-row:3; align-self:end; align-items:flex-end; text-align:right; font-size:11px`。
    - 数量 `count`：`grid-column:1; grid-row:4; align-self:end; font-size:12px`（当天工作记录条数）。
  - **热力底色**（按工作量）：`heat-0 = color-mix(green 7%)`，`heat-1..4` 逐级加深绿色透明；作为日格背景。
  - 其他月日期：`opacity:.42`。
  - 今天/选中：绿色描边（`border:1px solid --green` 或加粗环）。
- 悬停：轻微 `--hover` 底。

### 4.3 右侧提醒/工作卡（.work-calendar-tasks）
- 顶部选中日期标题（如"2026年11月1日"）。
- 区块"提醒事项"：提醒条目列表（时间点 + 内容），可新增。
- 区块"工作记录（1）"：当天工作记录摘要（数量徽标）。
- 宽度固定 340px，`contain:size`（不撑大月历）。

### 4.4 预览核对（07 工作日历）
- 工具栏左"‹ 2026年11月 📅 › 今天"，右"导入 导出 请假/外出/加班 新增提醒事项"。
- 左月历卡（周标题 周一..周日；日格 20px 日期+农历+提醒标记+条数；今天/选中绿描边）；右 340px 提醒事项卡（日期标题、提醒事项区、工作记录(1) 区）。42 天网格。

## 6. 响应式
- `@1200px`：`--reminder-width:280px`；日格 `padding:7`；`marks` 字号 10。
- 首页嵌入日历时：宽度撑满两列，右提醒栏仍 340（`container-type:inline-size`）。

---

## 7. 跨端实现要点
- 三个 Tab 用 `TabBar` + `TabBarView`（或 `IndexedStack` 保活，避免切换丢状态）。
- 工作记录表：`DataTable`/自建网格，列宽按上表；行高 64；类型用彩色 Tag/文本；系统列用下拉。
- 日历：`GridView` 7 列 42 格；每格 `Stack`/`Column` 摆放日期(20/750)、农历、右上标记列、底部记录数；热力底色用绿色透明度分层；今天/选中加绿描边。
- 右提醒栏 `SizedBox(width:340)`，内部 `ListView` 分"提醒事项""工作记录"两段。
