## 3. 字段定义表

### 3.1 列（`预览 08` 核对）
| 列 | 渲染 | 对齐 |
|---|---|---|
| 显示名 | 字段显示名（如"业务系统"） | 左 |
| 键名 | 灰色 chip（如 `businessSystem`，等宽/浅灰底小标签） | 左 |
| 类型 | 类型文字（14 种之一：文本/数字/日期/布尔/单选/多选/密码/标签…以实际下拉为准） | 左/中 |
| 必填 | `✓`（是则勾选图标，否则空） | 中 |
| 唯一 | `✓` / 空 | 中 |
| 快速复制 | `✓` / 空 | 中 |
| 默认值 | 默认值文本 / 空 | 左 |
| 校验·可选值 | 校验规则或可选值列表（如正则、选项枚举） | 左 |
| 模板填写说明 | 说明文本 | 左 |
| 操作 | 行内编辑/删除/上移下移等 | 右 |

（若含"操作"列则置于最右固定；否则行操作以内联图标呈现。以原型实际行为准。）

### 3.2 表格样式
- 全宽表，列多时**横向滚动**（滚动条位于表格底部；全局滚动条被隐藏，可保留可滚动能力）。
- 表头：`--table-header` 底、12px/600、内容居中、吸顶。
- 行：12px 正文；行间 1px `--line`；hover `--hover`。
- 键名 chip：浅灰底、圆角小、等宽字体、`--muted` 文字。
- 布尔列（必填/唯一/快速复制）用 `CheckOutlined` 绿色勾，空值留白居中。

### 3.3 预览核对（08 字段定义）
- 标题"字段定义"；页头右侧一长排按钮："导入模板 导出模板 导入字段模板▾ 保存字段 保存为模板 单位选择▾ 字段排序 新增字段"。
- 表头：显示名 / 键名 / 类型 / 必填 / 唯一 / 快速复制 / 默认值 / 校验·可选值 / 模板填写说明；表格可横向滚动。

## 5. 响应式
- `fields-page-heading` 右列 `minmax(0,1fr)`，按钮组自动换行、右对齐，不溢出。
- 表格列多时横向滚动，不压缩列宽。
- `@1250px`：`module-grid` 转单列（本页为固定表，不受影响）。

## 6. 跨端实现要点
- `Column`：页头（`Row`/`Wrap` 左标题 + `Spacer` + `Wrap` 按钮组）+ `Expanded` 表格卡片（`body padding:0`）。
- 表格用横向 `SingleChildScrollView` + `DataTable`（`columnSpacing` 受控），表头吸顶用 `SliverPersistentHeader` 或 `DataTable` 的 `headingRowHeight`。
- 键名 chip：`Container(padding h6 v2, color: inset, radius 4~6) + Text(monospace,muted)`。
- 布尔列：`Icon(Icons.check, color: green)` 或空 `SizedBox`，居中。
- 新增/保存/导入等按钮沿用 §00 按钮规范（primary 绿、default 描边、下拉带 `▾`）。
