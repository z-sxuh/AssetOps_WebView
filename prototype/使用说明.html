打开与保存

使用桌面版 Chrome 或 Edge，直接双击 HTML 即可离线运行。推荐窗口 1440×900。已保存修改保留在当前浏览器本地存储中，刷新后仍可查看；换浏览器、移动文件或清理浏览器数据可能使用不同存储。

右上角打开搜索，或按 F4；底栏切换早春、晨雾、浅夜、系统主题。点击“已解锁”可锁屏，使用演示主密码解锁。初始化界面使用独立存储，不影响主原型样例。

桌面能力的演示范围

请勿录入真实密码和业务数据。 本原型的演示数据与备份使用浏览器存储，没有正式应用的加密保险库。原型不会读取真实数据库、访问业务服务或修改 Windows 自启动、托盘、注册表。

自启动和桌面设置只保存演示状态；导出文件进入浏览器下载目录。Excel 只支持基础 .xlsx，不支持旧版 .xls 和复杂工作簿。历史 ZIP 和备份仅供原型内部演示，与正式应用格式不互通；留存清理仅按“保留最近”数量演示。离线原型不请求外部节假日接口。

二次开发与构建

源码保留原版 src/components、src/features 和样式文件。浏览器适配集中在 prototype/ 中，便于在浏览器中预览与调试。在仓库根目录运行 npm install、npm run dev；执行 npm run build 重新生成单 HTML。
