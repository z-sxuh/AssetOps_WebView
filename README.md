# AssetOps工作台

面向 Windows 的本地资产与运维管理应用，把服务器台账、系统资料、网络拓扑、工作日历、记录和备份集中在一个工作台中。

## 项目简介

工作台以单位、环境、区域和系统组织资产，适合记录服务器配置、账号信息与运维过程。业务数据保存在本地，支持主密码解锁和加密备份；离线使用，仅节假日调休需联网下载对应json。

## HTML 原型

本仓库同时在 [`prototype/`](prototype/) 目录保留了一份纯前端 HTML 原型：把界面打包成单个 HTML 文件，双击即可离线查看、无需后端，适合快速预览布局与交互。它只是静态演示（虚构样例数据），**不是**正式桌面应用，也不提供真实加密保险库。

- 直接打开：[`prototype/工作台-v1.2.5-HTML原型.html`](prototype/工作台-v1.2.5-HTML原型.html)
- 原型说明与源码：[`prototype/README.md`](prototype/README.md)

## 功能特性

- **系统导览**：查看服务器状态、单位资产数量、工作记录和工作日历。
- **资产台账**：按组织目录管理服务器，记录主机、IP、账号密码、磁盘和自定义字段；支持筛选、列设置、复制和批量操作。
- **系统运维**：编写 Markdown 系统资料，关联服务器资产，保存版本并查看或回滚历史资料。
- **网络拓扑**：通过设备素材和台账资产绘制节点、连线及区域，支持分组、对齐、连接点调整，以及 PNG、SVG、HTML 和 JSON 导出。
- **工作报告**：记录日常工作，收集和编辑报告，使用工作日历管理节假日、请假、加班和提醒事项。
- **字段定义**：按系统配置字段类型、必填、默认值及校验规则，并管理字段模板。
- **导入导出**：通过 Excel 导入预检、字段映射和冲突处理完成资产交换，也可按范围导出数据。
- **历史变更**：查看资产变更记录和字段差异，支持历史归档及回滚。
- **系统备份**：创建、检查、恢复和管理备份，支持自动备份与留存设置。
- **搜索与设置**：使用全局搜索快速定位内容；可配置主题、表格显示、自动锁定、托盘和开机自启动等选项。

## 安装与开发

应用仅支持 Windows x64。安装程序需要 WebView2 Runtime；目标电脑缺少运行时时，安装程序会通过微软引导程序下载。

在项目根目录准备依赖并启动桌面开发环境：

```powershell
.\src\scripts\setup-dependencies.ps1
Set-Location .\src\frontend
pnpm desktop:dev
```

在项目根目录构建 Windows 安装包：

```powershell
.\src\scripts\build-windows.ps1
```

默认sqlite数据库位于应用目录下的 `data/database/assets.db`，数据目录可通过配置调整。源码位于 `src/frontend/`，构建脚本位于 `src/scripts/`。
